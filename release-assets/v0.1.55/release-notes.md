# v0.1.55 — Logics buzzer execution and localization

- Adds direct Play and Stop testing to configured Buzzer Play nodes.
- Keeps group Start, Pause, Resume, and Stop state explicit and reports the active state through the Logics API.
- Animates wires belonging to running automations and retains pulse animation for actual executions.
- Translates dynamic Logics titles, ports, parameters, presets, palette categories, and runtime controls in all 20 supported interface languages.
- Uses compact, overflow-safe node and group controls for longer localized labels.
- Retains compact Logics persistence and startup recovery behavior from v0.1.54.
